# Odin Recipes

This is a basic recipe website built as part of The Odin Project's Foundations curriculum. 

## Skills Demonstrated
* Structuring web pages using semantic HTML5 boilerplate and elements (<h1>, <h2>, <p>, <ul>, <ol>, <li>)
* Linking multiple local HTML pages together using relative file paths (<a>)
* Embedding images with descriptive alt attributes (<img>)
* Managing project version control and committing changes with Git and GitHub
